# Janinas Moon

Ein kleiner Hof, nur für dich.

Spielen: https://kibaunrw-pixel.github.io/janinas-moon/

Auf dem Handy den Link öffnen und „Installieren“ bzw. „Zum Startbildschirm hinzufügen“ wählen. Danach läuft das Spiel wie eine App, auch ohne Internet. Der Spielstand bleibt auf dem Handy gespeichert.
